# Mémoire centrale

Source unique de vérité pour tous les agents. Markdown versionné. Chaque fichier commence par sa date de mise à jour.

Règles :
- Aucune donnée personnelle de client, prospect ou membre de salle. Les personnes sont désignées par leur rôle ou par un identifiant du CRM.
- Une information chiffrée cite sa source (Sheet CA, CRM, réponse de Marien, estimation).
- Quand deux sources se contredisent, les deux valeurs sont notées avec la question ouverte. Personne ne tranche à la place de Marien.
- Toute correction faite par Marien devient une règle dans `regles.md` ou un fait dans le fichier concerné.

| Fichier | Contenu |
|---|---|
| `business.md` | Identité, lieux, statut, chiffres de référence, canaux, outils |
| `offres.md` | Offres, tarifs datés, mécaniques commerciales, produits numériques |
| `positionnement.md` | Cibles, promesse, ton, mots à éviter |
| `avatars.md` | Avatar papas (en ligne), avatar débutant (présentiel) |
| `objectifs.md` | Objectifs chiffrés, horizon, contraintes de temps |
| `equipe.md` | Personnes qui interviennent (Clara, Sacha, Fitness Park) et règles d'attribution |
| `regles.md` | Règles commerciales, actions nécessitant validation, confidentialité, limites coaching |
| `journal.md` | Décisions et résultats, append-only |
