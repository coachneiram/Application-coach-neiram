# Audit d'automatisation

## Procédure

1. Lister les tâches manuelles (demander à Marien une semaine type ; compléter avec ce que la mémoire connaît : reprogrammation par blocs, report du CA, déclaration URSSAF, relances, réponses aux DM, bilans hebdo, factures, publication).
2. Pour chaque tâche : fréquence, durée par occurrence, heures par mois, difficulté, risque d'erreur ou de perte de relation si automatisée, outil possible (connecteur existant, Apps Script, script du dépôt, Routine), coût mensuel, temps gagné par mois.
3. Classer :
   - **AUTOMATISER MAINTENANT** : > 2 h/mois gagnées, risque faible, outil disponible.
   - **AUTOMATISER PLUS TARD** : gain réel mais dépend d'un connecteur absent (Instagram, site) ou d'une décision.
   - **RESTER HUMAIN** : relation client, vente, coaching, tout ce qui touche la santé.
4. Pour les « maintenant » : proposer l'implémentation la plus simple, dans ce dépôt ou dans les outils de Marien, avec critère de réussite.

## Format

| Tâche | Fréquence | h/mois | Risque | Outil | Coût | Gain h/mois | Verdict |

Puis les trois automatisations à faire, dans l'ordre, et ce qui prouvera qu'elles marchent.

## Règles

- Automatiser uniquement ce qui a une valeur mesurable. Pas de gadget.
- Toute automatisation qui envoie un message reste en mode brouillon tant que Marien n'a pas défini un workflow validé.
