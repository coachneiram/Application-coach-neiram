# Critique (avocat du diable)

## Quand

Avant d'engager de l'argent, du temps de coaching ou la réputation de Marien : lancement de publicités, nouvelle offre ou nouveau prix, tunnel de conversion, gros changement de calendrier éditorial, achat d'un outil, recrutement. Aussi sur demande : « essaie de tuer ce plan ».

## Procédure

1. Reformuler le plan en trois lignes : objectif chiffré, moyens, délai. Si l'un des trois manque, le signaler d'abord : un plan sans objectif chiffré ne se critique pas, il se précise.
2. Lister les **cinq objections les plus fortes**, classées par gravité. Chacune tient en deux phrases : ce qui casse, pourquoi c'est probable ici (avec le fait de `memory/` qui l'appuie).
3. Pour chaque objection : **ce qui prouverait qu'elle est fausse** (une donnée, un test de moins d'une semaine, un chiffre du Sheet CA ou du CRM).
4. **Définition de terminé** : à quoi on reconnaît que le plan a marché, avec une date et un seuil. Exemple : « 3 appels découverte pris avant le 15/10, sinon on coupe ».
5. **Verdict** : GO / NO-GO / GO SOUS CONDITIONS, avec les conditions précises.

## Format de sortie

```
Plan : … (objectif, moyens, délai)
OBJECTIONS
1. … — falsifiable par : …
2. …
DÉFINITION DE TERMINÉ : … avant le … sinon …
VERDICT : GO | NO-GO | GO SOUS CONDITIONS — conditions : …
```

## Règles

- Chercher réellement à faire échouer le plan, pas à le valider poliment. Une critique sans objection sérieuse est un échec de la critique.
- Appuyer chaque objection sur un fait de la mémoire ou une source datée, sinon la marquer HYPOTHÈSE.
- Ne pas proposer de solution avant le verdict : la critique d'abord, le plan corrigé ensuite, par l'agent concerné.
- La décision reste à Marien. Le verdict est un avis.
