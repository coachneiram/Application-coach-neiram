## 3. Analyse des dépôts GitHub

### `coachneiram/coach-neiram-app` (dernier push 06/09/2026)

Application client PWA, React 18 + Vite, déployée sur GitHub Pages par GitHub Actions, tests exécutés avant chaque mise en ligne (≈ 160 tests, tests de parité entre l'ancienne et la nouvelle version). Bascule Vite faite le 05/09. Planification GSD dans `.planning/` (9 phases, 8 terminées).

Fonctions : journal (repas, hydratation, poids, sommeil, pas), recherche d'aliments (catalogue local + Open Food Facts + photo + code-barres), séances et constructeur de séances, force athlétique, records, créneaux d'entraînement, plan de semaine, « semaine difficile » (bascule en format maintien), bilan hebdo et mensuel générés par IA, tendances, export / import JSON, mode hors ligne.

Infrastructure :
- Proxy Cloudflare Worker `coach-neiram-proxy` : route `/ai` (Gemini, clé côté serveur, modèles `gemini-3.6-flash` puis repli) et route `/coach-sync` (secret partagé).
- Google Apps Script `coach-sync.gs` : reçoit les événements et écrit dans le Sheet `Suivi Coaching en ligne`, envoie des e-mails plafonnés (3 par client et par jour, 20 au total).
- Événements : `pointage`, `justification`, `semaine_difficile`, `alerte_semaines_difficiles`, `alerte_seances_manquees` (2 créneaux manqués sur 14 jours), `alerte_decalages` (3 décalages sur 4 semaines), `resume_hebdo`. Carence de 7 jours entre deux alertes de même nature.
- Bouton « Prévenir mon coach » vers WhatsApp quand la synchro n'est pas configurée.
- Données client : 100 % sur le téléphone (`localStorage`). Aucune base serveur. Le coach ne reçoit que les événements et les bilans envoyés.

Conséquence pour le système : **le suivi d'adhérence des clients en ligne existe déjà et fonctionne.** L'agent Réussite client lira le Sheet `Suivi Coaching en ligne`, il ne recréera rien. Le point faible connu : le Sheet n'a reçu que des tests, aucun client réel n'est encore synchronisé.
